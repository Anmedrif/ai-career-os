# Roadmap

The roadmap is evidence-led. A feature should be added only when it solves a demonstrated problem without weakening privacy, traceability, or human control.

## Phase 1 — Documentation baseline

- [x] Define the reference architecture and agent contracts.
- [x] Define source governance and Human-in-the-Loop gates.
- [x] Document the career lifecycle and core workflows.
- [x] Create evaluation criteria, templates, and synthetic examples.
- [x] Add privacy, security, contribution, and publishing guidance.

## Phase 2 — Neutralization and release decisions

- [x] Replace personal profile content with a neutral reusable starter.
- [x] Remove maintainer-like background details from synthetic fixtures.
- [x] Simplify README positioning for recruiters and first-time adopters.
- [x] Select one simple repository-wide license.
- [ ] Complete final accessibility and plain-language review.
- [ ] Approve or reject public publication.

## Phase 3 — Validation support

- [ ] Add a small local relative-link checker.
- [ ] Add Markdown style checks with documented exceptions.
- [ ] Add secret and personal-data scanning configuration.
- [ ] Automate Mermaid rendering checks.
- [ ] Add structured terminology and state-label checks.
- [ ] Add test fixtures that contain synthetic edge cases only.

## Phase 4 — Structured local prototype

This phase requires a separate design decision.

- [ ] Define minimal machine-readable schemas for facts, decisions, sources, and evaluations.
- [ ] Prototype local-only orchestration with manual approval checkpoints.
- [ ] Add an audit log that avoids unnecessary personal data.
- [ ] Evaluate failure recovery, access boundaries, and export behavior.
- [ ] Document what remains manual.

## Phase 5 — Evaluation and accessibility

- [ ] Create a larger synthetic test set.
- [ ] Run inter-reviewer calibration exercises.
- [ ] Measure rubric agreement and document limits.
- [ ] Test keyboard, screen-reader, and low-vision usability for any interface.
- [ ] Perform a threat model before any hosted or connected version.

## Not scheduled

No hosted service, private-account automation, automatic job submission, candidate ranking, or consequential autonomous action is planned without a new need, risk assessment, and explicit human authorization.

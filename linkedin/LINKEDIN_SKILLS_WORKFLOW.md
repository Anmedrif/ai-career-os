# LinkedIn Skills Workflow

## Objective

Build a focused, evidence-aware skills list that supports the target role without turning interest, coursework, or self-assessment into professional experience.

## Skill classes

| Class | Example treatment |
|---|---|
| Experience-supported | Link to one or more verified roles or projects |
| Credential-supported | Name the credential and its current status |
| Portfolio-demonstrated | Link to an approved public artifact |
| Self-assessed | Use cautiously and avoid level inflation |
| Learning-stage | Include only when relevant and label proportionately |
| Unsupported or outdated | Remove or leave unfeatured |

## Process

1. Export or copy the current skills list into a private record.
2. Map each skill to evidence and a current target requirement.
3. Identify duplicates, vague terms, and obsolete tools.
4. Select a concise priority group for the target positioning.
5. Confirm the top skills appear naturally in Headline, About, Experience, or Projects.
6. Check that learning-stage AI or programming skills are not presented as advanced paid experience.
7. Request approval for removals, additions, and reordering.

## Review questions

- Can the person explain where and how each priority skill was used?
- Is the wording at the right level of specificity?
- Are tools separated from capabilities?
- Is the list consistent with the CV and interview examples?
- Could any skill imply confidential system access?

The output is a proposed skill map. Direct profile changes require separate authorization.

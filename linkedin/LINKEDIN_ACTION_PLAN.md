# LinkedIn Action Plan

This plan improves an existing account one section at a time. It does not authorize account access or edits.

## Order of work

| Step | Deliverable | Dependency | Approval |
|---|---|---|---|
| 1 | Target role and positioning statement | Verified profile and career goal | User decision |
| 2 | Headline | Approved positioning | Exact text |
| 3 | About | Headline direction and supported facts | Exact text |
| 4 | Experience | Resolved dates, titles, and public-use boundaries | Entry by entry |
| 5 | Skills | Evidence map and target relevance | Add/remove/reorder |
| 6 | Certifications | Current credential status | Exact display |
| 7 | Projects | Approved public artifacts | Exact descriptions |
| 8 | Featured | Public links and rights | Item by item |
| 9 | GitHub link | Published approved repository | Link and placement |
| 10 | Consistency review | Updated sections, CV, interview bank | Final profile review |

## Working rule

For each section:

1. receive or confirm the current content;
2. identify factual, positioning, privacy, and discoverability issues;
3. propose one improved English version;
4. explain the reasoning;
5. check every claim against the verified profile;
6. obtain content approval; and
7. request separate authorization before any direct edit.
